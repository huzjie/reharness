# FAQ

**Q: 这和微调模型有什么区别？**
微调改权重；reharness 改 harness。改 harness 便宜、可审计、可回滚，且 Harness2
实证弱模型 + 好 harness 能打赢强模型 + 默认 harness。

**Q: 为什么零依赖？**
便于任何环境秒级复现；所有矩阵运算用纯 Python 实现。

**Q: 优化器真的看不到正确答案吗？**
是。它只看到 trace（成功/失败 + 用了哪些组件）。lift 完全从执行证据里推。

**Q: 递归到底优化什么？**
优化"优化器自己的配置"（打分 rubric + 提议多样性），用的是同一个 PPC。
